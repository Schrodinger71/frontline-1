# Линия

Штабная игра о сухопутном фронте в духе Wargame: две стороны — **Запад** и **Восток** —
с городами и ключевыми точками, пехотой, мотопехотой, танками, артиллерией, ПВО, РЭБ и
авиацией (вертолёты, штурмовики, разведдроны, ударные дроны). Фронт вертикальный:
Запад слева, Восток справа, вся симуляция и ИИ — на сервере, браузер только рисует и
отправляет приказы.

```
npm install
npm start   # http://localhost:8081  (порт — переменная PORT)
```

## Режимы

- **Оборона** — обычный бюджет на расстановку, но выше доход от городов и точки держатся дольше под атакой. Противник получает больше стартового бюджета и наступает.
- **Наступление** — бюджет на расстановку больше (+40%), чтобы ударить первым. Противник обороняется и получает больше дохода.
- **Встречный бой** — бюджет и доход равны с обеих сторон.

Каждый режим можно сыграть **против бота** (у бота свой характер командования — решительный,
осторожный, методичный, нервный или упрямый, со своей манерой в эфире и темпом атак) или
**в дуэли по коду партии**: создаёте партию — получаете 4-буквенный код, соперник вводит его
в меню, чтобы занять свободную сторону. Код виден в заголовке экрана.

## Расстановка и экономика (как в Wargame)

Партия начинается фазой **расстановки**: у каждой стороны стартовый бюджет и зона высадки
(подсвечена на карте, своя половина по глубине). Во вкладке **«Закупка»** выбираете тип части
и цену, кликаете в своей зоне — часть встаёт там. Нажимаете «Готов» или ждёте таймера — бой
начинается, когда готовы обе стороны (бот готовится сам).

В бою идёт **доход** каждую секунду: тем больше, чем больше городов у вашей стороны — на него
можно докупать подкрепления рядом с любой своей точкой (не только в зоне высадки). Бот тоже
расставляется и докупается сам, с той же экономикой.

## Местность

- **Лес** — защита для любой части (укрытие снижает входящий урон).
- **Город** — дополнительная защита пехоте.
- **Дорога** — прибавка к скорости движения.
- Лес и дороги считаются той же формулой шума/кривых, что и отрисовка карты
  (`shared/terrain.js`), поэтому видимый лес на холсте совпадает с игровым.

## Приказы и характер командиров

Каждая часть — выбор ЛКМ, повторный клик по карте — марш; «Стоять» и «На базу» (авиация) —
в панели справа. У каждой части свой характер (решительный / осторожный / методичный /
нервный / упрямый), который чуть меняет точность в бою и реплики в эфире
(`server/phrases.js`) — как и характер командования стороны у бота.

**Части:** пехота, мотопехота, танки, арта, ПВО, РЭБ, вертолёт, штурмовик, разведдрон,
ударный дрон. Города и точки берёт пехота/мотопехота (`cap`), фронт сам едет по
захваченным точкам. РЭБ глушит чужую точность и сбивает дроны с управления.

## Устройство

```
server/   HTTP + WebSocket (ws), лобби и партии — вся игровая логика в server/engine.js
shared/   карта, типы частей, местность — общие чистые функции для сервера и клиента
client/   отрисовка (холст), интерфейс, лобби
```

Партии живут в памяти процесса — перезапуск сервера их обнуляет.
